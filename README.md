# 小明智能体 · 待办清单编程题

请把小明改造成一个待办清单智能体，让用户用中文对话管理自己的任务。项目已经提供聊天界面、可持久化的任务 API 和 DeepSeek 客户端。初次启动时，无论你说什么，小明都会回复「你好，欢迎使用小明智能体」。

## 快速开始

安装 Node.js 24.12 或更高版本，在项目根目录运行以下命令。

```sh
npm ci
npm run dev
```

打开 <http://127.0.0.1:3000>，发送一条消息即可看到初始回复。接入模型时，把 `.env.example` 复制为 `.env`，填写自己的 `DEEPSEEK_API_KEY`，再重启服务。详细步骤见[本地开发指南](GETTING_STARTED.md)。

## 基础要求

下面是一段验收对话。回复的措辞由你决定，每一步都应反映真实的任务状态。

| 用户对小明说     | 预期结果                                   |
| ---------------- | ------------------------------------------ |
| 帮我记一下买牛奶 | 新增待办「买牛奶」                         |
| 再记一条取快递   | 清单里多了一条「取快递」                   |
| 我有哪些任务？   | 列出两条任务，并能看出各自的完成状态       |
| 牛奶买好了       | 把「买牛奶」标记为已完成，「取快递」仍待办 |
| 取快递这条删掉吧 | 删除「取快递」                             |
| 再给我看看清单   | 只剩已完成的「买牛奶」                     |

请让用户能通过聊天完成创建、查看、标记完成和删除这四种操作。任务应保存到本地，刷新页面或重启服务后仍可查询。可以从 [server/agent.ts](server/agent.ts) 开始，在这里接收对话历史并返回本轮回复。任务接口的路径、字段和返回值见 [OpenAPI 说明](server/openapi.yaml)。

## 可选扩展

选做你感兴趣的方向，也欢迎提出自己的想法。

- 为任务设置截止日期，并回答「今天有哪些任务到期？」
- 创建子任务并管理它们的完成状态。
- 改进清单的展示，让用户更容易看出哪些任务还需要处理。
- 为任务增加优先级和工作量（如小、中、大）。

## 模型费用

完成本题所产生的 DeepSeek API 实际调用费用可报销，**每人最多人民币 20 元**。运行初始项目和测试任务 API 无需密钥，也不会产生模型费用。请将密钥保存在本地 `.env` 中。
